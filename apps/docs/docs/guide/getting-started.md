# 快速开始

## 环境要求

- Node.js >= 22（推荐使用 [mise](https://mise.jdx.dev/) 管理，仓库已提供 `mise.toml`）
- pnpm 9

## 安装依赖

```bash
mise exec -- pnpm install
```

## 本地开发

```bash
# 启动插件开发模式（自动打开带插件的 Chrome）
mise exec -- pnpm dev

# 启动文档站
mise exec -- pnpm dev:docs
```

## 构建

```bash
# 构建全部（插件 + 文档站）
mise exec -- pnpm build
```

插件产物位于 `apps/extension/.output/chrome-mv3/`，可在 `chrome://extensions` 开启开发者模式后「加载已解压的扩展程序」。

## 创建第一条规则

1. 点击浏览器工具栏中的插件图标，打开 popup
2. 点击「管理规则」进入规则管理页
3. 点击「+ 返回值 Mock」创建示例规则，按需修改匹配模式后勾选启用

## 查看规则命中

规则动作执行后，扩展图标徽标会立即点亮，表示**当前标签页有规则生效**。徽标只表达状态，不显示数字。

打开 popup 可以看到具体数量：

- 顶部显示本页两条通道合并后的命中总数。
- 已产生命中的规则会高亮，规则卡片右上角的角标显示该规则的命中数。
- 点击规则后的跳转按钮，可进入规则管理页并自动定位、高亮对应规则。
- 「清空」按钮会重置当前标签页的命中日志、角标、高亮状态与图标徽标。

同一业务规则一次请求若执行重定向与 Header 改写两个动作，会计为 2 次命中。命中日志在顶层导航开始时自动清空，Hash 与 SPA 同文档跳转不会重置。

单个标签页最多保留最近 1000 条命中；超出后会丢弃最早的记录并在 popup 中提示。
